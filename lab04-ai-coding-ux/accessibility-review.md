# Accessibility Review Checklist

| รายการตรวจ | ผ่าน / ไม่ผ่าน | สิ่งที่แก้ไข / ข้อสังเกต |
|---|---|---|
| ข้อความหลักบนพื้นขาว Contrast >= 4.5:1 | ผ่าน | ใช้สี `#111827` บนพื้นขาว อ่านง่ายชัดเจน |
| ปุ่มหลักมี Contrast เพียงพอ | ผ่าน | ใช้สี `#1E40AF` ข้อความสีขาว Contrast ผ่านเกณฑ์ |
| ทุกช่องกรอกมี Label ที่มองเห็น | ผ่าน | เพิ่ม `<label>` ด้านบนทุกช่อง |
| ช่องบังคับกรอกมีสัญลักษณ์ชัดเจน | ผ่าน | ใส่ดอกจันสีแดง `*` และระบุ "(จำเป็น)" |
| Error ไม่ได้ใช้สีเพียงอย่างเดียว | ผ่าน | เพิ่มไอคอน ⚠️ และข้อความอธิบายวิธีแก้ไข |
| ลำดับการกด Tab เรียงถูกต้อง | ผ่าน | เรียง tabindex จากบนลงล่าง ซ้ายไปขวา |
| ปุ่มมีชื่อบอกหน้าที่ชัดเจน | ผ่าน | เปลี่ยนจาก "OK" เป็น "บันทึกสินค้า" และ "ยกเลิก" |

### จุดที่ AI ร่างพลาดแล้วทำการแก้ไขเอง (อย่างน้อย 2 จุด):
1. **AI ใช้ Placeholder แทน Label:** ในตอนแรก AI สร้างช่องกรอกโดยใส่แค่ข้อความจางๆ ข้างใน พฤติกรรมนี้ขัดกับหลัก Accessibility จึงได้ทำการเพิ่ม Label ลอยไว้ด้านบนช่องกรอก
2. **ใช้สีแดงอย่างเดียวแจ้ง Error:** AI กำหนดให้ช่องกรอกเปลี่ยนเป็นขอบสีแดงเมื่อเกิด Error โดยไม่มีข้อความบอก ได้แก้ไขโดยเพิ่มข้อความอธิบายใต้ช่อง เช่น "กรุณากรอกตัวเลขจำนวนเต็มที่มากกว่า 0"
