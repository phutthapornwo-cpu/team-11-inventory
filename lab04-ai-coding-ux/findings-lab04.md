# Interview Findings - Lab 04

## Interviewee (role-play): 
พนักงานจัดส่งและดูแลสต็อกสินค้า / ประสบการณ์ 5 ปี / ใช้อุปกรณ์หลักเป็น แท็บเล็ตแอนดรอยด์ราคาประหยัด และ สมาร์ตโฟนส่วนตัว

## Needs:
* ต้องการระบบที่เช็กจำนวนสินค้าคงเหลือได้แบบเรียลไทม์ และค้นหาสินค้าได้เร็วโดยไม่ต้องพิมพ์ชื่อเต็ม
* ต้องการปุ่มกดขนาดใหญ่ที่สามารถใช้นิ้วโป้งกดได้สะดวกขณะยกของหรือถือแท็บเล็ตมือเดียว

## Pain Points:
* ระบบเดิมมีตัวหนังสือและปุ่มเล็กเกินไป ทำให้กดผิดบ่อยเวลารีบจัดของ
* ข้อความแจ้งเตือน error อ่านไม่เข้าใจ เช่น ขึ้นว่า "Error Code 500" โดยไม่บอกว่าต้องแก้ไขอย่างไร
* หน้าจอโหลดช้า และกรอกฟิลด์ข้อมูลเยอะเกินไปโดยไม่จำเป็น

## Surprises:
* พนักงานมักเลือกบันทึกข้อมูลใส่กระดาษก่อน แล้วค่อยมาคีย์ลงระบบทีเดียวตอนเลิกงาน เพราะคีย์หน้างานไม่สะดวก

## Point of View (1 ประโยค):
พนักงานคลังสินค้าที่ต้องยกของไปด้วยต้องการหน้าจอเพิ่มและค้นหาสินค้าที่มีปุ่มขนาดใหญ่และระบุข้อความผิดพลาดที่เข้าใจง่าย เพื่อให้บันทึกสต็อกได้ทันทีหน้างานโดยไม่ต้องย้อนกลับมาคีย์บนกระดาษ
